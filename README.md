# Silent Waters — wedding quote estimator

Public quote estimator for Silent Waters Private Villa, Montego Bay, Jamaica.

A single self-contained `index.html`: no build step, no external JavaScript, no dependencies.
Mobile-first, six steps, and a mailto/clipboard hand-off to the villa at the end.

**This repository holds the published page only.** The rate cards, menus, the pricing audit and
the internal working notes are kept privately and are deliberately not published here.

Every price lives in the `PRICES` object at the top of the script, with each value commented to
the document and page it came from.

Estimates are indicative. The final quote comes from Silent Waters.
